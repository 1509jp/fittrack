# FitTrack

Sistema de acompanhamento fitness desenvolvido em React.

## Funcionalidades

- Cadastro de treinos
- Edição e exclusão de treinos
- Dashboard com estatísticas
- Gráfico de evolução
- Tema dark mode
- Persistência com localStorage
- Busca de exercícios
- Resumo semanal
- Sistema de metas

## Tecnologias utilizadas

- React
- React Router DOM
- Recharts
- CSS3
- JavaScript
